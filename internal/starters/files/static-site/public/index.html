Static site

It's live.

These are plain files. No server process runs for them: the box's edge serves public/ over HTTPS, with compression and caching.

  1. Make it yours

    Edit public/index.html and public/styles.css. Add pages, images, anything.

  2. Ship it

    Run tiffin deploy in this folder. Every deploy is kept, so tiffin rollback site brings the last one back in a second.

  3. Grow it

    Need a build step? Add a package.json with a build script: the box runs bun run build and serves dist/.

Served by one box.
